01 / Components

Use primitives for jobs, not decoration.

Each Bootstrap component below has a defined interaction purpose and an explicit accessible relationship.

Component boundaries stay visible.

Bootstrap owns layout and interaction primitives. Project CSS owns the visual identity. Project JavaScript owns theme persistence and demo validation.

Relationships are explicit.

Tabs, accordion triggers, modal labels, offcanvas labels, form labels, feedback, and navigation targets use unique IDs with matching ARIA references.

Markup assumptions are checked in CI.

The quality gate detects duplicate IDs, broken local targets, placeholder links, missing labels, inline event handlers, and invalid component references.

This repository is specifically a Bootstrap integration exercise, so the maintained demo keeps a pinned local Bootstrap 5.3.1 runtime instead of depending on a CDN at page load.

The page does not need an icon font. Removing that dependency keeps the active interface smaller and avoids using decorative icons where text is clearer.

Bootstrap's bundle handles Bootstrap behavior. Application policy—theme persistence and validation—lives in testable modules rather than inline snippets.
